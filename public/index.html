ข้อ 1: Bot จ่ายเงินล่ม / Lease Timeout (Heartbeat) Self-Healing

Bot Claim ออเดอร์แล้วเกิดแครชหรือหมดเวลา Lease ระบบจะตรวจจับและคืนเข้าคิวแบบ Exponential Backoff (สูงสุด 3 ครั้งก่อน DELAYED)

ข้อ 2: แย่งออเดอร์พร้อมกัน (Race Condition) SKIP LOCKED

ยิง Bot-A และ Bot-B แย่งเคลมออเดอร์ในมิลลิวินาทีเดียวกัน ป้องกันจ่ายซ้ำด้วย `SELECT ... FOR UPDATE SKIP LOCKED`

ข้อ 3: Webhook ธนาคารมาซ้ำ / มาช้า Idempotency

ทดสอบส่ง Webhook พร้อม Event ID ซ้ำ (ไม่ทำซ้ำ) หรือส่งหลังหมดอายุ (ตีเป็นคืนเงินอัตโนมัติ)

ข้อ 4: เติมไม่สำเร็จ (UID ผิด vs ระบบค่ายล่ม) Classification

แยก Transient Error (ค่ายล่ม 503 → Retry) กับ Permanent Error (UID ผิด → FAILED ทันทีให้ลูกค้าแก้)
